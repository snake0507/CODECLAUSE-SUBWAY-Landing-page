# Subway Landing Page

A front-end landing-page project created during a web development internship/practice task. It contains HTML and CSS files and image assets used to build a Subway-inspired page layout.

## Technologies

- HTML
- CSS

## Files

- `clickhere.html` — HTML page in the project
- `card.css` and `Untitled-1.css` — stylesheets
- Image assets used by the page

## Run locally

Clone or download the repository and open the relevant HTML file in a browser. If the page references assets using relative paths, keep the images and CSS files in their existing relative locations.

## Note

This is a learning/demo front-end project and is not an official Subway website or affiliated product.
